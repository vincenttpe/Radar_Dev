# 回覆語言

- 所有回覆、說明、摘要、審查意見與提問，一律使用繁體中文，採台灣慣用詞彙（例如「程式」「資料庫」「檔案」「設定」，不用「程序」「數據庫」「文件」「配置」）。
- 不使用簡體字。
- 程式碼、指令、檔名、路徑、函式與變數名稱、錯誤訊息原文維持原樣，不翻譯。
- 專有名詞第一次出現時可附英文原文，例如「知識圖譜（knowledge graph）」。
- Git commit 訊息與程式碼註解跟隨 repo 現有慣例（本 repo 文件與註解為繁體中文）。
