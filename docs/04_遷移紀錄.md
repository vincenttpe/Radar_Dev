## 程式修改

1. `build_embeddings.py`：`PASSWORD` 改為讀環境變數 `NEO4J_PASSWORD`（沒設定會直接報錯）；`URI`、`USER` 改為可用環境變數覆寫，預設值不變。
2. `Project1.py`：`DATA_DIR`、`CSV_PATH`、`JSON_PATH` 改指向 repo 根目錄的 `data/`。`--input` 的相對路徑原本接在 `Project1.py` 所在資料夾，樣本搬走後會找不到；改為先以目前工作目錄為準，找不到再接在 `data/samples/` 下（`--input 01.json` 與 `--input data/samples/01.json` 都可用）。命令列說明裡的舊路徑 `/home/nvidia/Desktop/宏貿/data` 改為 `data/samples/`，並拿掉不存在的 `--output` 範例（報告只印在終端機）。其餘邏輯未動，Neo4j 密碼預設值仍是原 README 公開的 `password123`。
3. `kg/v1/graph.cypher`、`kg/v1/metrics.json`：下肢肌力與心肺耐力 3 分、4 分建議的「很好」「良好」用詞與等級顛倒，已互換。`kg/source/graph.docx` 與 `kg/dumps/` 未改。
4. `Dockerfile`：拿掉 `ENV NEO4J_PASSWORD=...`，改為執行時傳入。注意 Dockerfile 的 `COPY . .` 是以 `legacy/prototype/` 為建置目錄設計的，資料已移到 repo 根目錄，若要再用需調整建置目錄。
