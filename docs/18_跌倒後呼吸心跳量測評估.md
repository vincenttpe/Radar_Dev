# 跌倒後量測呼吸心跳的評估（2026-10-21）

**背景**：上一代產品能用雷達量呼吸與心跳，FDA 申請中；但量不到血壓、血糖等資訊，無法完整取代醫療等級監測，市場受限，所以從中取出部分功能做成本產品。這裡評估能不能在長者跌倒後量呼吸心跳，提供照護人員參考。決定記在 ADR 0009（proposed）。

## 1. 結論

- **已定（2026-10-21）**：跌倒後才啟動；結果不能用來解除、降級或延後警報（ADR 0009 規則 1、2）。
- **技術上**：「有沒有呼吸起伏」最可行；呼吸率在部分情境可行；跌倒後的心跳數字最不可靠。
- **建議**：先只在內部記錄、累積驗證數據（階段 A），不要直接把數字給照護人員看。

## 2. 跌倒後量測的難處

上一代產品熟悉的是「躺在床上、距離固定、姿勢固定」，跌倒後的情境差很多。

| 問題 | 說明 | 影響 |
|---|---|---|
| 距離與角度 | 人倒在地上時可能在視野邊緣，或被馬桶、床擋住；距離越遠回波越弱。有研究在 1.6 m 時呼吸率吻合（16 對 16 次／分），3.44 m 時心跳偏差大（71 對 87 次／分）[1] | 高 |
| 姿勢 | 趴著量到的是背部起伏，振幅較小；側躺時位移方向和雷達視線斜交。心跳位移只有零點幾毫米，比呼吸小一個數量級，最先受影響。床上睡姿的研究已有心跳約 3.6%、呼吸約 9.1% 的誤差 [2] | 心跳高、呼吸中 |
| 衣物 | 乾的薄衣物對 60 GHz 影響小，濕的衣物衰減明顯 [3]。浴室是跌倒最常見的地方 | 浴室高、其他中 |
| 身體動作 | 長者可能掙扎、發抖、想爬起來，照護人員也會進場；只有靜止時量得準 | 中 |
| 多人 | 照護人員靠近時可能量到錯的人；機構廁所本來就是多人場域 | 中 |
| 時間窗口 | 呼吸率約需 10–30 秒穩定訊號，和語音確認的等待（10 秒、重問一次）重疊 | 低 |

## 3. 風險：讓人以為沒事

長者跌倒後沒有回應，畫面卻顯示「呼吸 16、心跳 72」，而那可能是量到旁邊的人或雜訊；照護人員就可能晚一點才去。所以 ADR 0009 規定生理數據不能讓警報往下調。另外：

- 「無法量測」要明確顯示，不能用最後一次讀值補。
- 每次輸出附量測品質（距離、姿勢、有沒有其他人）。

## 4. 分階段做法（待公司決定）

| 階段 | 做什麼 | 給誰 | 定位影響 |
|---|---|---|---|
| A | 跌倒後記錄呼吸心跳估計值與品質指標，只存內部用於驗證 | 沒有人 | 不改定位；要決定資料存哪裡 |
| B | 只給狀態：「偵測到呼吸起伏／未偵測到／無法量測」 | 居服員 | 要先做法規諮詢 |
| C | 顯示呼吸率、心跳數字 | 照護人員 | 走醫療器材路線，和上一代產品的 FDA 申請一起規劃 |

在跌倒情境給照護人員生理數字，預期用途已接近醫療用途；加「僅供參考」通常改變不了判定。台灣沒有查到雷達生理監測的專門判定公告，要向 TFDA 申請個案諮詢；和 FDA 申請中的上一代產品宣稱是否互相牽動，要請法規顧問評估（ADR 0008、`docs/05` F11）。

## 5. 驗證計畫（階段 A）

- **情境**：仰躺、趴、左右側躺、半坐靠牆 × 距離（依實際安裝位置，例如 1、2、3 m）× 衣物（薄、厚、濕）× 場所（浴室、臥室），另加有無第二人在場。
- **參考標準**：呼吸用胸帶，心跳用心電圖或血氧機，同步記錄。
- **指標**：
  - 平均絕對誤差與 Bland–Altman 圖；
  - 能給出有效讀值的時間比例；
  - **錯誤安心率**：實際沒有呼吸或數值異常時，系統卻顯示正常的比例，這是最關鍵的安全指標。
- **對照門檻**：心跳監測常引用 AAMI EC13 的 ±10% 或 ±5 bpm（取較大者）；呼吸率臨床上常用 ±2–3 次／分。
