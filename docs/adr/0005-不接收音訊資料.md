# 本 repo 不接收、不保存、不處理音訊資料

邊緣裝置送出的音訊 `.bin` 含長者語音，屬個人資料。本 repo 只用裝置事件與描述句；音訊的保存期限、存取權限與刪除由現有系統負責。本 repo 在 Jetson 上和音訊檔共用機器時，程式也不讀取該目錄。

## 考慮過的做法

- **用音訊補強判斷**（例如辨識呼救內容）：主動呼救已經由裝置判定、以 `mode=speech` 的裝置事件送出，本 repo 不需要原始語音；接收音訊反而要擔起語音資料的保護。

## 後果

- 一旦接收過音訊，就無法撤回已經流出的資料，所以要改這個決定，屬單向門「個人資料的流向」，要另寫 ADR 取代本篇。
