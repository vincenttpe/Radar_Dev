# 甲方週報由 Dashboard 產生，本 repo 不產生週報

甲方每週要看的跌倒次數與活動量，直接從裝置事件統計就算得出來，不需要知識圖譜，所以改由 Dashboard 從雲端或 Jetson 的資料計算。本 repo 只交出知識圖譜的等級判定，以及各 Profile 的文字或語音報告。

## 考慮過的做法

- **本 repo 產生週報**：本 repo 曾做過第 1 版，已移除。同一個數字由兩邊各算一次，口徑容易不一致；當時定下的統計規則與踩過的問題交接在 `docs/07_週報交接_Dashboard.md`。

## 後果

- 不要在本 repo 加回週報。本 repo 的使用趨勢（`--trend`）是否也改由 Dashboard 算，尚待決定（`docs/14` 4-8）。
