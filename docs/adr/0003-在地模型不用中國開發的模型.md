# 在地模型不用中國開發、或以中國模型為基底的模型

Jetson 上的在地模型（改寫、提問對應、照護紀錄、句庫起草），以及評估時拿來比較的模型，都不用中國開發的模型，也不用以它們為基底微調、蒸餾或量化的版本。例如 Qwen、DeepSeek（含 `deepseek-r1-distill-llama` 這類蒸餾版）、GLM／ChatGLM、百川、InternLM、MiniCPM、Yi、混元。

舊雛形用的 Qwen2.5-0.5B（`docs/01`、`legacy/`）只留作歷史紀錄，新系統不沿用。

## 怎麼執行

- **選型時**：每個候選模型都要看 model card，記下開發者、base model（一路追到最底層）與授權，寫進選型紀錄；base model 查不到的不用。
- **評估工具**：`radar-model-eval` 依模型名稱擋下常見的中國模型家族（`src/radar_agent/model_policy.py`），不送任何題目。名稱檢查只是提醒，改過名字的模型擋不住，最後仍以 model card 為準。
- **部署時**：Jetson 上實際載入的模型檔，名稱與雜湊要和選型紀錄一致（部署程式之後再做）。

**非台灣訓練的模型可能夾雜簡體字與大陸用語**，目前輸出檢查擋不下來，見 [#22](https://github.com/vincenttpe/Radar_Dev/issues/22)。

## 考慮過的做法

- **只限制部署、不限制評估**：評估時用中國模型當比較基準，數字會被拿去當選型理由；一併不用比較單純。

## 後果

- 台灣團隊以 Llama 為基底的繁體中文模型（Breeze2、TAIDE）是優先候選：有繁體中文續訓，基底也不是中國模型（Breeze2 的視覺部分待決定，見「候選更新（2026-10-27）」）。
- 小模型的繁體中文與台語能力仍要實測；台語輸出（F6）若小模型做不到，維持範本或句庫。
- 授權條款（Llama、Gemma、TAIDE 各自不同）要在選型時確認是否允許商用與在機構現場部署（F2）。
