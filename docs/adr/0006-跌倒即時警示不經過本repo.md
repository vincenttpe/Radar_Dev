# 跌倒即時警示不經過本 repo

跌倒警示走秒級的即時路徑：裝置判定、本地警報、語音確認、雲端通知居服員，都不經過知識圖譜、在地模型或本 repo。本 repo 只在分析路徑上，產生事件摘要、處置提示與各 Profile 的報告。分析路徑故障不影響警示。

理由：結案驗收要求系統緊急通報時間 < 10 秒（`docs/08` KPI 3）；分析路徑要讀一段時間的資料、查知識圖譜、跑在地模型，不保證秒級回應，警示也不能因為報告程式出錯而送不出去。

## 後果

- 本 repo 的程式不在警示的關鍵路徑上，失敗時不用處理「警示漏送」，但也不能宣稱縮短了通報時間。
- 處置提示若之後要和即時警示合成一則通知，延遲與失敗處理要重新設計，要另寫 ADR（`docs/14` 4-3）。
