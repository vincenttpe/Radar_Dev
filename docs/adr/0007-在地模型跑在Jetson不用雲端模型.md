# 給讀者的文字由 Jetson 上的在地模型產生，不送雲端模型

本 repo 執行時產生給讀者的文字（改寫、提問對應、照護紀錄），用跑在現場 Jetson PC 上的小型在地模型，不呼叫雲端的大型語言模型。評估初期不會有高階伺服器，以小型模型為準（待確認事項第 5 項）。因為模型小、能力有限，事實一律由規則與知識圖譜決定，模型只改說法（`docs/02`「三個原則」第 2 條），沒過檢查就退回範本。

這個決定只管本 repo 把資料送進哪個模型。裝置資料本身預設仍會同步到雲端（`docs/02` 第 1 點），那屬於現有系統的範圍。句庫草稿由 AI 起草（ADR 0002），在哪裡起草尚未決定。

## 後果

- 模型選型以 Jetson 跑得動的大小為準，並受 ADR 0003 限制。
- 檢查擋不到的，兜底是人工審核佇列，不是換更大的模型。日後若要考慮雲端模型，只能送去識別的事實組合，需另行決策（`docs/02` 第 120 行），要另寫 ADR 取代本篇。
