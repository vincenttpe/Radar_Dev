# 文字由 Jetson 上的在地模型產生，不送雲端模型

改寫、提問對應、照護紀錄與句庫起草，都用跑在現場 Jetson PC 上的小型在地模型，不呼叫雲端的大型語言模型。長者資料因此不離開現場；代價是模型小、能力有限，所以事實一律由規則與知識圖譜決定，模型只改說法（`docs/02`「三個原則」第 2 條），沒過檢查就退回範本。

## 考慮過的做法

- **雲端模型**：品質較好，但長者的事件與等級要送出現場；客戶要求不同步到雲端時（`docs/02` 第 1 點）也無法使用。

## 後果

- 模型選型以 Jetson 跑得動的大小為準，並受 ADR 0003 限制。
- 檢查擋不到的，兜底是人工審核佇列，不是換更大的模型。日後若要考慮雲端模型，只能送去識別的事實組合，要另寫 ADR 取代本篇。
