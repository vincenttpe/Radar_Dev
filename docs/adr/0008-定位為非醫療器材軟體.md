# 定位為非醫療器材軟體，輸出不使用醫療用語

本系統定位為非醫療器材軟體：輸出是照護輔助資訊，不是醫療判斷。所以所有給讀者的文字（範本、句庫、在地模型的改寫，連地點名稱也一樣）都不能出現「診斷、治療、處方、保證」，模型改寫時也不能用；檢查沒過就不輸出。

## 後果

- 用詞表看起來嚴格（例如地點叫「治療室」時整段摘要都會被擋，`docs/10` D-3），這是刻意的，放寬前要先確認不影響定位。
- 資料或建議若之後用於臨床判斷、成為智慧醫療系統的一環，定位可能要重新評估（`docs/05` F11），由公司決定；定位改變時要另寫 ADR 取代本篇。
