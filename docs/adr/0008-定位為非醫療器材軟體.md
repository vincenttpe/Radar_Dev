# 定位為非醫療器材軟體，輸出不使用醫療用語

本系統定位為非醫療器材軟體：輸出是照護輔助資訊，不是醫療判斷（待確認事項第 9 項，已確認）。所以給讀者的文字不能出現醫療用語，檢查沒過就不輸出。

## 現在的做法與尚未決定的部分

- **已決定**：非醫療器材定位。
- **尚未決定**：禁用詞的完整清單、必要的免責聲明由誰訂（`docs/05` F5）。程式目前暫定擋「診斷、治療、處方、保證」四個詞（`output_check.py` 的 `FORBIDDEN`），範本與在地模型的改寫都要通過。
- **例外**：照搬的知識圖譜原文（等級名稱、建議、建議量、原文）不檢查用詞，因為它另有單向門「知識圖譜內容」與審核人把關。
- **尚未決定**：地點名稱要不要檢查（`docs/10` D-3，兩個選項都還沒勾）。程式目前照樣檢查，所以地點叫「治療室」時整段摘要會被擋下。

## 後果

- 放寬用詞檢查前，要先確認不影響定位。
- 資料或建議若之後用於臨床判斷、成為智慧醫療系統的一環，定位可能要重新評估（`docs/05` F11），由公司決定；定位改變時要另寫 ADR 取代本篇。
